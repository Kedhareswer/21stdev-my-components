# Biryani Legends: real assets

**Status: done (2026-10-31).** This was the handoff for replacing the drawn
art with real assets. It is now the record of where each file came from and
how it was made.

## What exists

`components/biryani-legends-template` ships with art made in code: three
drawn SVG engravings, three canvas-painted pots and a generated paper grain.
That stays the default. The real assets are data only. The component did not
change.

| Path | What it is |
|---|---|
| `legends/*.webp` | The seven full-size files, ready to serve from an app's `public/legends/`. |
| `originals/*.jpg` | The three generated pot photographs as they came out (1264 × 1264, on grey), before the cut-out. They cannot be regenerated identically. The engravings are re-fetchable from the URLs below. |
| `components/biryani-legends-template/demo-photos.tsx` | The book with these assets, embedded as `data:` URIs (AVIF, and WebP for the paper), 184 KB. |
| `cover.png`, `thumb.webp` | Shot from `demo-photos.tsx`. |

**The rule for every asset:** public domain, CC0, or generated by us. No
watermarks. No stock licences. Adobe Stock "free" images are not allowed:
their licence does not allow redistributing the file inside a publicly
installable component.

## Processing (Python 3, Pillow, NumPy)

**Pots.** A flat-difference mask, as the original handoff suggested, punched
holes through pale rice and the cream enamel, and kept the soft grey shadow.
So the background is only the light, low-chroma grey that is connected to
the frame edge. Neutral grey enclosed by the handle loops goes too.

```python
# cutout_pot.py  in.png out.webp [quality]  -> transparent, cropped, padded 1000 x 1000 WebP
import sys
import numpy as np
from PIL import Image, ImageFilter, ImageDraw
im = Image.open(sys.argv[1]).convert("RGB")
a = np.asarray(im).astype(np.int16)
chroma = a.max(2) - a.min(2); light = a.mean(2)
cand = ((chroma < 16) & (light > 120)).astype(np.uint8) * 255
m = Image.fromarray(np.pad(cand, 1, constant_values=255)).copy()   # copy: fromarray's buffer is read-only
ImageDraw.floodfill(m, (0, 0), 128)
bg = np.asarray(m)[1:-1, 1:-1] == 128
h, w = chroma.shape; yy, xx = np.mgrid[0:h, 0:w]
neutral = (np.hypot(xx - w / 2, yy - h / 2) > 0.36 * w) & (chroma < 10) & (light > 120)
loops = Image.fromarray(neutral.astype(np.uint8) * 255).filter(ImageFilter.MinFilter(9)).filter(ImageFilter.MaxFilter(13))
bg |= (np.asarray(loops) > 0) & neutral                              # handle loops, not rim highlights
mask = Image.fromarray((~bg).astype(np.uint8) * 255).filter(ImageFilter.MinFilter(3)).filter(ImageFilter.GaussianBlur(1.0))
out = im.convert("RGBA"); out.putalpha(mask); out = out.crop(out.getbbox())
side = max(out.size); sq = Image.new("RGBA", (side, side)); sq.paste(out, ((side - out.width) // 2, (side - out.height) // 2))
pad = int(side * 0.06); canvas = Image.new("RGBA", (side + pad * 2,) * 2); canvas.paste(sq, (pad, pad))
canvas.resize((1000, 1000), Image.LANCZOS).save(sys.argv[2], "WEBP", quality=int(sys.argv[3]) if len(sys.argv) > 3 else 74, method=6)
```

**Engravings.** The scans are hand-coloured, so the script reads
`max(R, G, B)` rather than luminance. That way the colour washes count as
paper and only the engraved line becomes ink. It also crops away the plate
border and the engraved imprint text, such as titles and signatures.

```python
# ink_to_alpha.py in.jpg out.webp x0 y0 x1 y1 lo gain quality maxw
import sys
import numpy as np
from PIL import Image, ImageOps
x0, y0, x1, y1 = map(int, sys.argv[3:7]); lo, gain = float(sys.argv[7]), float(sys.argv[8]); q, maxw = int(sys.argv[9]), int(sys.argv[10])
im = Image.open(sys.argv[1]).convert("RGB").crop((x0, y0, x1, y1))
g = ImageOps.autocontrast(Image.fromarray(np.asarray(im).max(2)), cutoff=1)
alpha = np.clip((255 - np.asarray(g).astype(np.float32) - lo) * gain, 0, 255).astype(np.uint8)
ink = Image.new("RGBA", g.size, (58, 46, 34, 255)); ink.putalpha(Image.fromarray(alpha))   # sepia-graphite ink
w = min(maxw, g.width); ink = ink.resize((w, round(g.height * w / g.width)), Image.LANCZOS)
ink.save(sys.argv[2], "WEBP", quality=q, alpha_quality=q, method=6)   # alpha is the picture: lossless alpha is 4x bigger
```

**Paper.** The mottling is band-limited noise filtered in the frequency
domain, so it is periodic and the tile repeats without a seam. Laid lines
repeat every 4 px and chain lines every 128 px. Faint curved fibres are
drawn nine times, shifted, so they wrap across the tile edges. The base tone
is `#efe3c6`. The script asserts that the seam differs no more than the
interior does, then saves WebP at quality 88.

**Demo embeds.** `demo-photos.tsx` must stay under 21st's 200,000-byte limit
for a demo file. Its copies are therefore smaller:
- pots: 480 px, AVIF quality 36
- Tellicherry: 1300 px, AVIF quality 12
- Ambur: 900 px, AVIF quality 14
- Lucknow: 800 px, AVIF quality 20
- paper: WebP quality 55

At equal bytes, AVIF keeps engraved line work continuous, where WebP's lossy
alpha dithers it into blocks. `tests/biryani-legends-template.test.mjs`
checks the size limit and that the demo fetches nothing.

## Wiring in your own app

Serve the files from your app, for example from `public/legends/`. Do not put
them in `components/`: only the `.tsx`, the demos and the README live there.

```tsx
import BiryaniLegendsTemplate, { BL_LEGENDS } from "@/components/ui/biryani-legends-template"

const legends = BL_LEGENDS.map((l, i) => ({
  ...l,
  dish: { ...l.dish, src: ["/legends/faiza-handi.webp", "/legends/selvarajan-clay.webp", "/legends/sonia-enamel.webp"][i] },
  engravingImage: [
    { src: "/legends/tellicherry.webp", aspect: 2.6, alt: "Engraving of the harbour at Tellicherry, East Indiamen at anchor before the fort" },
    { src: "/legends/ambur-fort.webp", aspect: 1.85, alt: "Engraving of the hill fort at Ambur above the plain" },
    { src: "/legends/lucknow-garden.webp", aspect: 1.4, alt: "Engraving of the mosque of the Great Imambara at Lucknow across its garden" },
  ][i],
}))

<BiryaniLegendsTemplate legends={legends} paperTexture="/legends/paper.webp" />
```

The engravings sit inside the layout's box (the bottom band, the top-right
oval or the top-left oval), are masked soft at the edges, and are revealed by
an ink sweep. They need transparent paper. The box is an isolated
compositing group, so its `multiply` cannot blend with the page, and an
opaque white ground would show as a white block.

The plates differ from the original brief in a few ways:
- Tellicherry is Vandergucht's 1736 view, not the Forbes and Shury plate in
  *Oriental Memoirs*.
- Lucknow is the Great Imambara mosque across its garden, with figures. It
  has no cypresses and no palanquin.
- The plates' engraved titles and signatures were cropped out.
