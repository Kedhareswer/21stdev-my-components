# Repair Bay: rendered assets

**Status: done (2026-10-31).** This records where each render came from
and how it was made.

The component draws its own scene as SVG when it gets no images
(`demo-drawn.tsx`). The renders are data only. `demo.tsx` passes them in.

| Path | What it is |
|---|---|
| `originals/scene.jpg` | The workshop, 1680 × 944, as generated. |
| `originals/poster.jpg` | The same bench on a flat mustard backdrop, 1680 × 944, as generated. |
| `originals/mechanic.jpg` | Close-up of the mechanic, 1264 × 1264, as generated. |
| `public/*.webp` | Full-size copies to serve from an app's `public/` (WebP q84). `poster-cutout.webp` has alpha. |
| `components/repair-bay-concept-template/demo.tsx` | The same four, embedded as AVIF `data:` URIs: 165 KB of base64 in all. |
| `cover.png`, `thumb.webp` | Shot from `demo.tsx`. |

**The rule for every asset:** generated by us, public domain or CC0. No
watermarks and no stock licences.

## How they were made

1. **Generated with Canva `generate-image`, 16:9 and 1:1.** The poster and
   the close-up were generated with the scene as their image reference, so
   the characters, the bench and the light match.
2. **Exported.** Each image was placed full-bleed on its own page (pages 5–7)
   of the scratch design "Blank photo scratch canvas" and exported as PNG.
3. **Brought into the sandbox through Wonder's `fetch_image_content`.** The
   session's network policy blocks Canva's hosts, and that tool fetches the
   export URL on Wonder's side.

They cannot be regenerated identically.

  reflected in the brass goggles as he solders the robot, and jellyfish
  bokeh behind.

## Processing (Python 3, Pillow 12 with AVIF, NumPy)

**Poster cut-out.** A soft chroma key on "yellowness":
- `min(R, G) − B` is high on the backdrop and low on the dark bench and the
  pale fox. It ramps from 70 to 130.
- The key is gated by brightness, with R ramping from 95 to 140.
- The key fades out towards the floor.
- The mask is eroded by one pixel and feathered by 0.8 px.

Any backdrop pixels left in the cut-out sit exactly over the identical
poster, so they only show where the title passes behind them. The image is
cropped to the top 62% (585 px), the only part that ever overlaps the
title, and fully transparent pixels are zeroed so it compresses well.

```python
a = np.asarray(poster).astype(np.float32); R, G, B = a[..., 0], a[..., 1], a[..., 2]
s = np.clip((np.minimum(R, G) - B - 70) / 60, 0, 1) * np.clip((R - 95) / 45, 0, 1)
s *= np.clip((0.80 - np.arange(h)[:, None] / h) / 0.06, 0, 1)
alpha = Image.fromarray(((1 - s) * 255).astype(np.uint8)).filter(ImageFilter.MinFilter(3)).filter(ImageFilter.GaussianBlur(0.8))
```
